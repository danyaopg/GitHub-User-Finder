# GitHub User Finder

**Автор:** [Новиков Данил]

## Описание

Приложение для поиска пользователей GitHub с возможностью сохранения избранных пользователей в локальный JSON‑файл. Реализовано с использованием:
* `tkinter` — для графического интерфейса;
* `requests` — для работы с GitHub API;
* локального JSON‑хранилища — для избранного.

## Использование API GitHub

Приложение использует публичный API GitHub по адресу:
`https://api.github.com/users/{username}`

API возвращает JSON с данными пользователя, включая:
* логин (`login`);
* полное имя (`name`);
